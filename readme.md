# 🏃‍♂️ 4x4 Pro Max – Interval Running App for Apple Watch

**4x4 Pro Max** is a SwiftUI-based Apple Watch app designed for serious runners and interval enthusiasts. The app guides users through a structured 4x4 high-intensity interval training workout, tracks live metrics via HealthKit, and saves results for later review on a companion iPhone app.

---

## 📲 Features

- ⏱ **Predefined 4x4 workout**:
  - 5 min warm-up
  - 4x (4 min run + 3 min jog)
  - 5 min cooldown
- 📍 **Indoor/Outdoor run selection**
- ❤️ **Live heart rate**
- 📏 **Real-time distance tracking**
- 🏃‍♀️ **Speed/Pace display**
- 🔄 **Runs in background**
- 📱 **iPhone companion app (coming soon)**

---

## 🧠 Built With

- **SwiftUI** for modern UI
- **HealthKit** for workout tracking and heart rate
- **WatchKit** for Apple Watch integration
- **Xcode 15+** and **watchOS 10+**
